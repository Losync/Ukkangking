1. Pendahuluan

Gambaran umum tentang website Sofia Snack.

Sofia Snack adalah website e-commerce sederhana bertema toko kue yang dibangun sebagai proyek Uji Kompetensi Keahlian (UKK) SMK. Website ini memungkinkan pelanggan untuk menelusuri produk kue, menambahkan ke keranjang, dan melakukan pemesanan. Di sisi lain, admin dapat mengelola kategori, produk, dan pesanan melalui dashboard admin yang terpisah.

3. Cara Instalasi & Menjalankan

Langkah-langkah dari awal hingga website dapat diakses.

1

Clone atau Copy Proyek

Salin folder proyek ke direktori kerja Anda.

2

Install Dependency PHP

Buka terminal di folder proyek, lalu jalankan:

composer install
3

Install Dependency JavaScript

npm install
# atau jika menggunakan Bun:
bun install
4

Konfigurasi File .env

Salin file .env.example menjadi .env, lalu edit bagian database:

cp .env.example .env

Buka file .env dan sesuaikan:

APP_NAME="Sofia Snack"

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ukkangking
DB_USERNAME=root
DB_PASSWORD=
5

Generate Application Key

php artisan key:generate
6

Buat Database

Buat database kosong bernama ukkangking di MySQL (bisa lewat phpMyAdmin atau terminal).

7

Jalankan Migrasi & Seeder

Ini akan membuat semua tabel dan mengisi data awal (admin, kategori, produk):

php artisan migrate --seed
8

Buat Storage Link

Agar gambar yang diupload bisa ditampilkan:

php artisan storage:link
9

Jalankan Server

Buka 2 terminal terpisah:

# Terminal 1 - Laravel Server
php artisan serve

# Terminal 2 - Vite (Tailwind CSS)
npm run dev
10

Akses Website

Buka browser dan kunjungi:

http://localhost:8000
⚠️
Penting: Kedua terminal (Laravel server & Vite) harus tetap berjalan selama development. Jika Vite tidak jalan, tampilan CSS tidak akan muncul.

6. Autentikasi (Login & Register)

Sistem login dan registrasi user.

Cara Kerja

Autentikasi menggunakan implementasi manual (tanpa package Breeze/Jetstream) melalui AuthController.

User buka /login → Isi email & password → AuthController validasi → ✅ Redirect ke home

File Terkait

FileFungsi
AuthController.phpHandle login, register, logout
AdminMiddleware.phpCek apakah user adalah admin
views/auth/login.blade.phpTampilan halaman login
views/auth/register.blade.phpTampilan halaman registrasi

Alur Login (AuthController)

public function login(Request $request)
{
    // 1. Validasi input
    $request->validate([
        'email' => 'required|email',
        'password' => 'required',
    ]);

    // 2. Coba login dengan Auth::attempt
    if (Auth::attempt($request->only('email', 'password'), $request->remember)) {
        $request->session()->regenerate();

        // 3. Jika admin, redirect ke dashboard admin
        if (auth()->user()->is_admin) {
            return redirect()->route('admin.dashboard');
        }

        // 4. Jika user biasa, redirect ke home
        return redirect()->route('home');
    }

    // 5. Jika gagal, kembali ke form login
    return back()->withErrors(['email' => 'Email atau password salah.']);
}

Proteksi Admin (Middleware)

AdminMiddleware mengecek apakah is_admin == true. Jika bukan admin, user akan di-redirect ke halaman utama.

public function handle(Request $request, Closure $next)
{
    if (!auth()->check() || !auth()->user()->is_admin) {
        return redirect()->route('home')
            ->with('error', 'Akses ditolak.');
    }
    return $next($request);
}

// ProductController@index
public function index(Request $request)
{
    $query = Product::where('is_active', true)->with('category');

    if ($request->search) {
        $query->where('name', 'like', '%'.$request->search.'%');
    }
    if ($request->category) {
        $query->whereHas('category', function($q) use ($request) {
            $q->where('slug', $request->category);
        });
    }

    $products = $query->latest()->paginate(12);
    $categories = Category::all();

    return view('products.index', compact('products', 'categories'));
}

8. Fitur Keranjang Belanja

Sistem keranjang belanja berbasis session.

Cara Kerja

Keranjang belanja disimpan di session (bukan database), sehingga tidak memerlukan login. Data keranjang berupa array yang tersimpan di session('cart').

Klik "Tambah" → Simpan ke Session → Tampil di Keranjang → Checkout

Struktur Data Session Cart

session('cart') = [
    product_id => [
        'name'     => 'Nastar Keju',
        'price'    => 45000,
        'quantity' => 2,
        'image'    => 'products/nastar.jpg',
    ],
    // ... produk lainnya
];

Fungsi-Fungsi Cart

MethodURLAksi
add()POST /cart/add/{product}Menambah produk ke keranjang
update()PATCH /cart/update/{product}Mengubah jumlah produk
remove()DELETE /cart/remove/{product}Menghapus produk dari keranjang
index()GET /cartMenampilkan isi keranjang

Kode: Menambah ke Keranjang

public function add(Request $request, Product $product)
{
    $cart = session()->get('cart', []);
    $qty = $request->input('quantity', 1);

    if (isset($cart[$product->id])) {
        $cart[$product->id]['quantity'] += $qty;  // Tambah jumlah
    } else {
        $cart[$product->id] = [                   // Tambah baru
            'name'     => $product->name,
            'price'    => $product->price,
            'quantity' => $qty,
            'image'    => $product->image,
        ];
    }

    session()->put('cart', $cart);
    return back()->with('success', 'Produk ditambahkan!');
}

9. Fitur Checkout & Pengurangan Stok

Proses pemesanan dan mekanisme pengurangan stok otomatis.

Alur Checkout

Keranjang → Cek Stok → Isi Form → Simpan Order → Kurangi Stok → ✅ Sukses

Mekanisme Pengurangan Stok

Saat checkout, sistem akan:

  1. Validasi stok — memastikan stok cukup untuk semua item di keranjang
  2. Database Transaction — menggunakan DB::beginTransaction() agar semua operasi berhasil atau semua gagal
  3. Lock for Update — mengunci baris produk agar tidak terjadi race condition (2 user checkout bersamaan)
  4. Decrement stok — mengurangi stok produk sesuai jumlah yang dipesan

Kode Checkout (Bagian Inti)

public function store(Request $request)
{
    $cart = session()->get('cart', []);

    try {
        DB::beginTransaction();            // Mulai transaksi

        // Verifikasi stok & kunci baris
        foreach ($cart as $productId => $item) {
            $product = Product::lockForUpdate()->find($productId);
            if ($product->stock < $item['quantity']) {
                DB::rollBack();
                return back()->with('error', 'Stok tidak cukup!');
            }
        }

        // Buat pesanan
        $order = Order::create([...]);

        // Simpan item & kurangi stok
        foreach ($cart as $productId => $item) {
            OrderItem::create([...]);
            Product::where('id', $productId)
                ->decrement('stock', $item['quantity']); // STOK BERKURANG
        }

        DB::commit();                      // Simpan semua perubahan
    } catch (\Exception $e) {
        DB::rollBack();                    // Batalkan jika error
        return back()->with('error', 'Terjadi kesalahan.');
    }

    session()->forget('cart');              // Kosongkan keranjang
    return redirect()->route('checkout.success', $order);
}
✅
Contoh: Jika produk "Nastar Keju" memiliki stok 30, dan user memesan 2, maka stok otomatis menjadi 28 setelah checkout berhasil.

public function store(Request $request)
{
    $request->validate([
        'name'        => 'required|string|max:255',
        'category_id' => 'required|exists:categories,id',
        'price'       => 'required|numeric|min:0',
        'stock'       => 'required|integer|min:0',
        'image'       => 'nullable|image|max:2048',
    ]);

    $data = $request->except('image');
    $data['slug'] = Str::slug($request->name);
    $data['is_active'] = $request->boolean('is_active');

    if ($request->hasFile('image')) {
        $data['image'] = $request->file('image')
            ->store('products', 'public'); // Simpan gambar
    }

    Product::create($data);
    return redirect()->route('admin.products.index')
        ->with('success', 'Produk berhasil ditambahkan!');
}

public function updateStatus(Request $request, Order $order)
{
    $request->validate([
        'status' => 'required|in:pending,processing,completed,cancelled',
    ]);

    $order->update(['status' => $request->status]);

    return back()->with('success', 'Status pesanan berhasil diperbarui!');
}
